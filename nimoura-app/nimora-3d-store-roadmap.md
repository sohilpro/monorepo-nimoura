# نقشه راه روزانه: ساخت فروشگاه سه‌بعدی Nimora

## روز ۱: پوسته مغازه (Shell)

- [ ] نصب TresJS در Nuxt 4 و ساخت صفحه `/store-3d` (فقط کلاینت)
- [ ] ساخت فایل `theme3d.ts` که توکن‌های پالت را به رنگ‌های Three.js تبدیل می‌کند
- [ ] ساخت کف، چهار دیوار، سقف و قاب ورودی
- [ ] نور پایه (ambient گرم + یک directional نرم) و پس‌زمینه
- [ ] تنظیم دوربین اولیه در ورودی

**خروجی:** یک اتاق خالی زیبا با رنگ‌های درست که روی موبایل و دسکتاپ بالا می‌آید.

## روز ۲: قفسه‌ها و مبلمان

- [ ] ساخت کامپوننت پارامتریک `<Shelf>` (عرض، تعداد طبقه، رنگ، لبه رزگلد)
- [ ] ساخت قفسه‌های سه دیوار و قفسه طاق‌دار پشتی
- [ ] ساخت میز مرکزی مخملی و پیشخوان صندوق
- [ ] افزودن آینه‌ها، فرش، گلدان و دکور ساده

**خروجی:** مغازه کاملاً مبله ولی بدون محصول.

## روز ۳: نورپردازی و حال‌وهوا

- [ ] افزودن ریسه نور پشت قفسه‌ها و spotlight روی میز مرکزی
- [ ] افزودن لوستر سقفی و درخشش لوگو
- [ ] افزودن Post-processing سبک: Bloom ملایم و Vignette (فقط دسکتاپ)
- [ ] استفاده از سایه تماسی (contact shadow) زیر قفسه‌ها به‌جای سایه ریل‌تایم
- [ ] افزودن ذرات ریز شناور (گرد و غبار طلایی) برای حس لوکس

**خروجی:** صحنه‌ای که اسکرین‌شاتش را می‌شود در شبکه‌های اجتماعی گذاشت.

## روز ۴: حرکت و کنترل

- [ ] دسکتاپ: WASD + موس (PointerLock) یا کلیک برای رفتن
- [ ] موبایل: جوی‌استیک مجازی + کشیدن برای چرخش
- [ ] پیاده‌سازی **حالت راحت**: نقاط تلپورت (ورودی، پوست، آرایش، عطر، صندوق) با دکمه‌های منوی گوشه
- [ ] افزودن برخورد ساده با دیوارها و قفسه‌ها
- [ ] افزودن انیمیشن نرم دوربین بین نقاط

**خروجی:** قدم‌زدن راحت در مغازه، حتی برای کاربر ناآشنا با بازی.

## روز ۵: اتصال محصولات به قفسه‌ها

- [ ] گرفتن محصولات از API موجود سایت
- [ ] **مسیر سریع (بدون تغییر دیتابیس):** چیدمان خودکار بر اساس دسته‌بندی؛ هر دسته به یک قفسه نگاشت می‌شود
- [ ] نمایش هر محصول به‌صورت جعبه کوچک با تکسچر عکس اصلی (بسته‌بندی)
- [ ] استفاده از اطلس تکسچر و `InstancedMesh` برای بهبود کارایی
- [ ] نمایش محصولات ناموجود به‌صورت کمرنگ با برچسب «ناموجود»

**خروجی:** قفسه‌ها با محصولات واقعی سایت پر می‌شوند.

## روز ۶: تعامل و خرید داخل صحنه

- [ ] پیاده‌سازی hover/لمس: هایلایت محصول + برچسب نام و قیمت
- [ ] پیاده‌سازی کلیک: نزدیک‌شدن دوربین به محصول و بازشدن کارت جزئیات
- [ ] افزودن دکمه «افزودن به سبد» با استفاده از **همان store و API سبد سایت فعلی**
- [ ] نمایش هاله سبز `success` و تیک پس از افزودن محصول
- [ ] افزودن لینک «مشاهده صفحه کامل» به صفحه دوبعدی محصول
- [ ] افزودن مینی‌کارت شناور و دکمه «رفتن به صندوق» که به checkout سایت می‌رود

**خروجی:** از ورود تا پرداخت واقعی داخل تجربه سه‌بعدی.

## روز ۷: پرفورمنس و موبایل

- [ ] تشخیص قدرت دستگاه (GPU tier) و تعریف سه سطح کیفیت: کم / متوسط / بالا
- [ ] محدودکردن pixel ratio و خاموش‌کردن افکت‌ها روی دستگاه ضعیف
- [ ] Lazy-load بخش‌ها و فشرده‌سازی تکسچرها (WebP/KTX2)
- [ ] ساخت صفحه بارگذاری زیبا با درصد پیشرفت و لوگو
- [ ] پیاده‌سازی Fallback خودکار: اگر WebGL در دسترس نبود یا دستگاه خیلی ضعیف بود، کاربر به سایت دوبعدی هدایت شود
- [ ] هدف‌گذاری برای ۳۰ فریم پایدار روی موبایل متوسط

**خروجی:** تجربه روان روی گوشی‌های معمولی.

## روز ۸: اتصال به سایت فعلی

- [ ] افزودن دکمه ورود به مغازه سه‌بعدی در هدر و صفحه اصلی («بیا داخل مغازه»)
- [ ] افزودن دکمه «بازگشت به نمای ساده» داخل صحنه
- [ ] اشتراک session، لاگین و سبد خرید بین دو حالت
- [ ] افزودن متای SEO برای `/store-3d` و لینک‌های عمیق (مثلاً `/store-3d?zone=makeup`)
- [ ] پیاده‌سازی **Feature Flag**: امکان فعال‌سازی برای درصدی از کاربران یا فقط ادمین با یک سوئیچ

**خروجی:** دو نسخه سایت کنار هم و کاربر آزاد در انتخاب.

## روز ۹: پولیش و تست

- [ ] ساخت راهنمای اولین ورود (۳ مرحله: چطور حرکت کنم / روی محصول کلیک کن / سبد)
- [ ] افزودن صدای ملایم محیط (اختیاری، با دکمه خاموش)
- [ ] تست مرورگرها (Chrome، Safari iOS، Android) و اندازه‌های مختلف
- [ ] تست مسیر خرید کامل با Playwright
- [ ] ثبت ایونت‌های آنالیتیکس: ورود به 3D، کلیک محصول، افزودن به سبد از 3D، خرید از 3D
- [ ] افزودن Sentry برای خطاهای WebGL

**خروجی:** نسخه آماده انتشار بدون باگ بحرانی.

## روز ۱۰: پروداکشن

- [ ] بیلد و دیپلوی روی همان زیرساخت سایت فعلی
- [ ] تنظیم کش طولانی‌مدت برای assetهای استاتیک روی CDN
- [ ] لانچ نرم: ابتدا فقط ادمین، سپس ۱۰٪ کاربران و در نهایت همه
- [ ] مانیتور ۲۴ ساعته: نرخ خطا، FPS میانگین و نرخ تبدیل 3D در مقابل 2D
- [ ] اعلام نسخه جدید روی سایت و شبکه‌های اجتماعی

**خروجی:** نسخه جدید زنده و قابل نمایش.

## هشدارهای مهم و واقع‌بینانه

1. **صحنه پروسیجرال زیبا و شیک می‌شود، اما فوتورئال نخواهد بود.** استایل پیشنهادی «مینیمال لوکس / نیمه‌کارتونی نرم» است؛ هم زیباست و هم سبک. اگر بعداً واقع‌گرایی بالا لازم شد، باید مدل‌های Blender با نورپردازی Bake‌شده تهیه شوند.
2. **روزهای ۵ و ۶ به ساختار API فعلی وابسته‌اند.** اگر endpoint سبد خرید یا محصولات ساختار خاصی دارد، باید پیش از پیاده‌سازی آن بخش بررسی شود.
3. **روی دستگاه‌های ضعیف، محیط سه‌بعدی نباید نمایش داده شود؛ نه اینکه صرفاً کند کار کند.** پیاده‌سازی fallback در روز ۷ حیاتی است.
